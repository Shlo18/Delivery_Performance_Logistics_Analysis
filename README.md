# 🚚 Logistics Intelligence Dashboard

### Delivery Performance, Delay Risk & Logistics Efficiency Analysis

A data-driven **Logistics Intelligence Dashboard** built with Python and Streamlit to analyze delivery performance, identify delay risks, compare regional and market performance, and improve logistics decision-making.

* 🌐 **Live Dashboard:** `https://delivery-performance-logistics-analysis.streamlit.app/`
* 💻 **GitHub Repository:** `https://github.com/Shlo18/Delivery_Performance_Logistics_Analysis.git`

---

## 📌 Project Overview

The Logistics Intelligence Dashboard analyzes global supply chain and delivery data to identify operational inefficiencies and delivery risks.

The project transforms raw logistics data into interactive business insights using **Python, Pandas, Plotly, and Streamlit**.

The dashboard helps users understand:

* Delivery performance
* Delivery delays
* Late delivery risk
* Regional performance
* Market performance
* Shipping mode performance
* Order distribution
* Logistics efficiency

## 🚀 How to Run the Project Locally

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_LINK
```

### 2. Open the project

```bash
cd Delivery_Performance_Logistics_Analysis
```

### 3. Create a virtual environment

```bash
python -m venv .venv
```

### 4. Activate the environment

**Windows:**

```bash
.venv\Scripts\activate
```

### 5. Install dependencies

```bash
pip install -r requirements.txt
```

### 6. Run the Streamlit application

```bash
streamlit run app3.py
```

The dashboard will open in your browser.
